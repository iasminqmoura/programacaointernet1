# Atividade Prática – Todo List com JavaScript

## Objetivo

Este projeto tem como objetivo desenvolver uma aplicação web simples de lista de tarefas (Todo List), permitindo ao usuário gerenciar tarefas de forma dinâmica, sem recarregar a página, aplicando conceitos fundamentais de desenvolvimento com JavaScript.

---

## Descrição da Atividade

A aplicação permite ao usuário adicionar, visualizar e remover tarefas de uma lista, utilizando manipulação do DOM e eventos para atualizar a interface em tempo real.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Funcionalidades Desenvolvidas

- Campo de entrada para digitação de tarefas
- Botão para adicionar novas tarefas
- Exibição das tarefas em lista dinâmica
- Remoção individual de tarefas
- Marcação de tarefas como concluídas
- Limpeza completa da lista com confirmação
- Persistência de dados utilizando localStorage
- Atualização da interface sem recarregamento da página
- Animações ao adicionar e remover tarefas

---

## Requisitos Funcionais Atendidos

- Campo de entrada (input) para descrição da tarefa
- Botão "Adicionar" para inclusão de tarefas
- Lista de tarefas exibida dinamicamente
- Cada item contendo:
  - Descrição da tarefa
  - Botão para remoção individual
- Remoção de tarefas de forma independente

---

## Requisitos Técnicos Atendidos

- Utilização de JavaScript puro (Vanilla JS)
- Manipulação do DOM com:
  - `createElement`
  - `appendChild`
  - `remove`
- Uso de `addEventListener` para captura de eventos
- Atualização dinâmica da página sem reload
- Código organizado e estruturado em arquivos separados

---
